개인 상태만 내보내고 복원합니다. 자료 원본은 완성본 HTML에 포함되어 있습니다.

개인 데이터 내보내기

즐겨찾기, 읽기 상태, 노트, 선택 항목과 필터 설정을 JSON으로 저장합니다.

개인 데이터 복원

기본값은 합치기입니다. 같은 자료의 노트·상태가 겹치면 현재 기록을 유지합니다.

개인 기록 초기화

즐겨찾기·노트·읽기 상태·비교 선택을 지웁니다. 필터와 테마는 유지됩니다. 삭제 전 백업을 권장합니다.

검색 도움말·키보드

검색은 기본적으로 모든 양의 검색어를 만족하는 자료를 반환합니다.

검색 문법

  • "natural gradient": 정확한 구문
  • tag:Preconditioning: 특정 필드 검색
  • author:"Stephen Boyd", year:2024
  • -LLM: 제외
  • Adam | Shampoo: OR 그룹

키보드

  • / 또는 Ctrl/Cmd+K: 검색
  • ?: 도움말
  • T: 테마 전환
  • Esc: 열린 창 닫기

개인 연구 관리

즐겨찾기, 읽기 상태, 노트, 비교 선택은 localStorage에 저장됩니다. 백업 JSON을 주기적으로 내보내면 브라우저 데이터 삭제에 대비할 수 있습니다.

비교와 내보내기

체크 버튼으로 최대 4개를 선택해 비교합니다. 현재 필터의 전체 결과를 CSV로 저장합니다. 개인 노트도 별도 열에 포함됩니다. 선택 자료는 Plain/Markdown/BibTeX로 복사합니다. BibTeX는 메타데이터 기반 초안이므로 제출 전 원출처의 저자·학회 정보를 확인하세요.

필터 코드 불러오기

로컬 HTML에서는 공유 버튼이 필터 코드를 복사합니다. 같은 자료 목록을 가진 HTML에서 코드를 붙여넣으세요. 개인 기록 자체는 공유되지 않습니다.
