# Optimization Resource Atlas 4.0

머신러닝·딥러닝의 수학적 최적화 연구를 위한 참고문헌 탐색 페이지입니다. 원본 224개 항목을 유지하고 9개를 추가하여 총 233개 자료 항목을 제공합니다. 같은 문헌이 서로 다른 분야에 등록된 경우도 있어, 항목 수는 고유 문헌 수와 다릅니다.

## 바로 사용하기

1. 압축을 풀고 **index.html**을 브라우저에서 엽니다.
2. 자료명을 검색하거나 분야·난이도·접근 방식·읽기 상태를 선택합니다.
3. 제목 또는 **상세·노트**를 눌러 원문 링크와 개인 노트를 확인합니다.

서버, npm 설치, API 키가 필요하지 않습니다. 목록과 검색은 오프라인에서도 동작합니다. 외부 원문을 여는 데는 인터넷 연결이 필요합니다. 권장 환경은 최근 버전의 Chrome, Edge, Firefox, Safari입니다.

## 주요 기능

- 제목·저자·태그·편집 설명을 검색하고 AND / OR / 제외 / 구문 / 필드 검색을 조합합니다.
- 9개 분야와 6개 학습·연구 경로를 제공합니다. 경로에는 선수지식, 4단계 읽기 순서, 읽으며 확인할 질문이 있습니다.
- 즐겨찾기, 읽기 상태, 개인 노트, 최대 4개 자료 비교를 지원합니다.
- 카드와 표 보기 모두에서 읽기 상태·즐겨찾기·비교 선택을 사용할 수 있습니다.
- 현재 필터의 전체 결과를 CSV로 저장하고 선택 자료의 인용을 Plain / Markdown / BibTeX로 복사합니다.
- JSON 백업을 합치거나 교체하여 복원할 수 있습니다.
- 라이트·다크 테마, 모바일 탐색 접기, 키보드 탐색, reduced-motion 설정을 지원합니다.

## 검색 예시

| 입력 | 의미 |
| --- | --- |
| `Shampoo covariance` | 두 검색어 모두 포함 |
| `"natural gradient"` | 연속 구문 |
| `author:"Stephen Boyd"` | 저자 필드의 구문 |
| `tag:Preconditioning -LLM` | 태그 포함, LLM 제외 |
| `Adam \| Shampoo` | 어느 한 그룹이라도 만족 |
| `year:2024` | 연도 필드 검색 |
| `-"variance reduction"` | 해당 구문 제외 |

검색 필드: `title`, `author`, `tag`, `year`, `notes`, `category`/`cat`, `id`. `notes:`는 자료의 편집 설명을 검색합니다. 개인 노트는 검색 대상에 포함되지 않습니다. 모든 일반 검색은 대소문자를 구분하지 않는 부분 일치입니다. 따옴표 안의 `|`는 OR 연산자가 아닙니다.

`/` 또는 `Ctrl/Cmd+K`: 검색 · `?`: 도움말 · `T`: 테마 전환 · `Esc`: 열린 대화상자 닫기. 입력 중이거나 대화상자가 열린 경우 전역 단축키를 제한합니다.

## 개인 기록과 이전 버전

기록은 이 브라우저의 localStorage에 저장됩니다. 기존 v3 키와 자료 ID를 유지하며 v2 데이터도 이전합니다. 단, 파일 이름·경로 또는 브라우저가 바뀌면 `file://` 저장 공간이 달라질 수 있습니다. 이전 HTML에서 **백업 → JSON 다운로드** 후 새 HTML에서 복원하면 가장 확실합니다.

복원의 기본값은 **합치기**입니다. 즐겨찾기는 합집합, 비교 선택은 현재 선택 우선으로 4개까지, 노트·읽기 상태 충돌은 현재 기록 우선입니다. 필터는 현재 설정을 유지합니다. **백업으로 교체**는 확인 후 백업의 기록·필터로 바꿉니다. 알 수 없는 ID는 제외되며 지원하지 않는 버전·잘못된 JSON 구조는 적용되지 않습니다. 가져오기 제한은 10 MiB입니다.

노트는 입력할 때 즉시 저장합니다. 영구 저장을 사용할 수 없으면 페이지 상단과 노트 상태에 안내하고, 현재 세션에서 기록을 유지합니다. 이 경우 창을 닫기 전에 JSON 백업을 내려받으세요. 계정 간 동기화 기능은 없습니다.

## 공유·인용·내보내기

- 웹서버에서 열면 **현재 뷰 공유**가 필터 URL을 복사합니다.
- 로컬 파일에서 열면 필터 코드(`#?...`)를 복사합니다. 받는 사람은 같은 버전 페이지의 **도움말 → 필터 코드 불러오기**에 붙여넣습니다.
- 공유되는 것은 필터 조건입니다. 개인 노트·읽기 상태·즐겨찾기는 JSON 백업으로 옮깁니다. 개인 상태 필터를 공유하면 각 브라우저의 기록에 따라 결과가 달라집니다.
- CSV에는 전체 필터 결과, 자료 ID, 편집 설명, 개인 노트가 별도 열로 들어갑니다. UTF-8 BOM을 포함하며 수식으로 해석될 수 있는 셀을 보호합니다.
- BibTeX는 제공된 메타데이터로 만든 초안입니다. 고유 ID를 포함한 인용 키, 복수 저자의 `and`, 특수문자 이스케이프를 적용합니다. 학회·권호·쪽수 등 확인되지 않은 정보는 만들지 않습니다. 제출 전 원문과 대조하세요.
- 인쇄는 현재 화면에 로드된 결과를 대상으로 합니다. 전체 필터 결과의 보관에는 CSV를 사용하세요.

## 소스 수정과 재생성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 모든 코드·데이터가 포함된 실행본 |
| `src/index.template.html` | 접근성 레이블과 UI 구조 |
| `src/styles.css` | 테마, 반응형 화면, 인쇄 스타일 |
| `src/app.js` | 검색, 필터, 저장, 복원, 비교, 내보내기 |
| `data/resources.json` | 자료 목록·서지정보·원문 링크 |
| `data/site-meta.json` | 분류, 버전, 갱신일, 학습 경로 |
| `build.py` | 표준 라이브러리만 사용하는 HTML 생성·검증 |
| `tests/regression.test.cjs` | Node 내장 테스트로 실행하는 회귀 검증 |
| `docs/CHANGELOG.ko.md` | 검토 결과와 변경 내역 |
| `docs/reference-audit.json` | 23개 수정의 근거 URL과 9개 추가 자료 |

소스를 수정한 뒤 Python 3.9 이상으로 실행합니다.

```bash
python3 build.py
python3 build.py --check
```

Windows에서는 `python` 또는 `py -3`를 사용해도 됩니다. 생성된 `index.html`만 정적 호스팅에 올리거나 다른 사람에게 전달하면 됩니다. `src/index.template.html`은 빌드용 템플릿이며 직접 실행하는 파일이 아닙니다.

Node.js 20 이상이 있으면 다음 테스트를 실행할 수 있습니다. 외부 패키지를 설치하지 않습니다.

```bash
node --check src/app.js
node --test tests/regression.test.cjs
```

자료를 추가할 때는 기존 ID를 재사용하지 말고 고유 ID를 부여하세요. 이미 저장한 기록을 유지하려면 기존 자료의 ID는 바꾸지 마세요. 새 항목의 `category`는 데이터 그룹 및 `categoryOrder`와 일치해야 합니다. 학습 경로의 단계는 실제 자료 ID를 참조해야 합니다. 발행연도를 확인하지 못한 상시 문서는 `year: null`로 표시합니다.

## 확인 범위

원본에서 발견한 주요 오류와 연구에 직접 도움이 되는 자료를 중심으로 서지정보를 대조했습니다. 전체 233개 항목의 모든 외부 URL에 대해 실시간 접속을 보증한 것은 아닙니다. 개별 대조 범위는 `verifiedFields`, 대조일은 `verifiedAt`에 기록합니다. 난이도·우선순위·읽기 순서는 편집상 권장안입니다.

17개 회귀 테스트, JavaScript 구문, 생성본 일치, 자료 ID·학습 경로·DOM ID 참조·URL 형식을 확인했습니다. 회귀 테스트의 DOM 대역은 렌더링 문자열과 상태 전이를 검사하며, 실제 브라우저 화면의 시각적 QA나 모든 브라우저의 접근성 검증을 대신하지 않습니다.
